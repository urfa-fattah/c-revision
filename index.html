1. What is C?

C is a general-purpose, procedural, compiled, structured programming language. It was developed by Dennis Ritchie at Bell Labs in the early 1970s (about 1972) and grew out of the earlier languages B (Ken Thompson) and BCPL. It was created to rewrite the UNIX operating system, which is why C gives so much control over memory and hardware.

Timeline of C standards

VersionYearNote
K&R C1978First book The C Programming Language by Kernighan and Ritchie
ANSI C / C89 (ISO C90)1989 / 1990First official standard; most textbooks follow this

Features of C

  • Procedural: a program is a collection of functions executed step by step.
  • Structured: code is organised with functions, loops and conditions, which makes it easy to read and debug.
  • Middle-level: mixes high-level readability with low-level power (pointers, bitwise operators).
  • Portable: the same source can be compiled on different machines.
  • Fast and efficient: compiled directly to machine code, with very little runtime overhead.
  • Small core, rich library: only 32 keywords in C89, with functions provided by stdio.h, math.h, string.h.
  • Extensible: the programmer can add new functions and library files.

Advantages

  • Fast execution
  • Direct memory access through pointers
  • Base for C++, Java, C#, Python's CPython
  • Works on tiny (embedded) to huge machines

Limitations

  • No object-oriented features
  • No automatic bounds checking on arrays
  • Memory must be managed manually
  • No exception handling or namespaces

Where C is used

Operating systems (UNIX, Linux kernel), device drivers, embedded systems and microcontrollers, compilers and interpreters, database engines, game engines, network software.

Semicolon ( ; )

The semicolon is the statement terminator. It tells the compiler where one statement ends.

Needed after

  • declarations: int a;
  • expression statements: a = b + 1;
  • function calls: printf("Hi");
  • return, break, continue, goto
  • do { } while (cond);
  • after the closing brace of struct / union / enum definitions

Not needed after

  • #include and #define lines
  • function header int main()
  • closing brace } of a block or function
  • if (cond), for (...), while (cond) headers
A stray semicolon is a silent bug 
int i;
for (i = 0; i < 3; i++);        // ; makes the loop body empty
    printf("Hi\n");              // runs only once, after the loop
The same happens with if (x > 0);. The compiler accepts it, so the program compiles but gives wrong output.

Syntax vs semantics

  • Syntax = grammar rules of C. A violation gives a syntax error at compile time.
  • Semantics = the meaning of the code. A wrong formula or wrong condition is a logical error: it compiles and runs, but the answer is wrong.

Each stage in detail

  1. Writing: type the code in an editor or IDE and save as prog.c.
  2. Preprocessing: handles every line starting with #. #include pastes the header file text, #define replaces macro names, comments are removed.
  3. Compilation: checks syntax, builds an internal tree, optimises and produces assembly code. Syntax errors and warnings appear here.
  4. Assembly: assembly is converted to machine code in an object file (.o / .obj). Calls such as printf are still unresolved.
  5. Linking: the linker joins object files with library code (the code of printf lives in the C library) and produces one executable. A missing function causes a linker error.
  6. Loading and execution: the operating system's loader copies the executable into memory and starts at main().

Commands with GCC

gcc prog.c -o prog          # all steps at once, executable named prog
./prog                      # run on Linux / macOS   (prog.exe on Windows)

gcc -E prog.c -o prog.i     # stop after preprocessing
gcc -S prog.c -o prog.s     # stop after compiling to assembly
gcc -c prog.c -o prog.o     # stop after assembling to an object file
gcc prog.o -o prog          # link only

gcc -Wall prog.c -o prog    # show all common warnings (always use this)
gcc prog.c -o prog -lm      # link the math library for sqrt, pow, sin ...

Type conversion

  • Implicit (automatic): in a mixed expression, the smaller type is promoted to the larger one: char → int → float → double.
  • Explicit (type casting): you force a type with (type) expression.

Decision statements let the program choose a path. C has: if, if-else, else-if ladder, nested if, switch (section 9) and the ?: operator (section 10).

9. switch # ✓

switch selects one block out of many by comparing a single integer or character expression with fixed case values. It is cleaner than a long else-if ladder when you test one variable against exact values.

switch (expression) {
    case value1:  statements;  break;
    case value2:  statements;  break;
    default:      statements;          // runs when nothing matches
}

Rules

  • The expression must be an integer type or char. Not float, double or a string.
  • Case labels must be constants (case 3:, case 'a':) and must be unique.
  • break leaves the switch. Without it, execution falls through into the next case.
  • default is optional and can be anywhere, but is normally last.
  • No ranges: case 1..5 is not standard C.

Example 1: day name

switch (day) {
    case 1:  printf("Saturday");  break;
    case 2:  printf("Sunday");    break;
    case 3:  printf("Monday");    break;
    default: printf("Invalid day");
}

    case 1:  printf("One ");
    case 2:  printf("Two ");        // matched here, no break...
    case 3:  printf("Three ");      // ...so this runs too

}

Complete CGPA calculator with switch (input-safe)

Edge cases this program handles
  • Bad input: letters, empty lines, extra characters (3.2abc), nan / inf, numbers that are too long. It asks again instead of crashing.
  • Ranges: course count 1 to 12, marks 0 to 100, credit above 0 and up to 6, previous CGPA 0 to 4.
  • Decimals: credits such as 1.5 or 0.75 are allowed. Marks are rounded to the nearest whole number first (79.5 becomes 80, 39.4 becomes 39).
  • Boundaries: 80, 75, 70 ... 40 land in the correct grade because the switch uses marks / 5.
  • Letter grades: upper or lower case and extra spaces are accepted. Invalid letters such as E, A++, C- are rejected.
  • F grade: counted with 0.00 points and its credit, plus a warning line.
  • Previous semesters: if the previous credits are 0, CGPA equals the semester GPA, otherwise the weighted average is used.
  • End of input: Ctrl+D (Ctrl+Z on Windows) stops the program with a message.
  • Division by zero: guarded, although it cannot happen once credits must be above 0.

/* ---------- safe input helpers ---------- */
static void readLine(char *buf, int size)
{
    if (fgets(buf, size, stdin) == NULL) {            /* EOF: Ctrl+D / Ctrl+Z */
        printf("\nInput ended. Program stopped.\n");
        exit(1);
    }
    char *nl = strchr(buf, '\n');
    if (nl != NULL) {
        *nl = '\0';                                   /* remove the newline */
    } else {                                          /* line was too long */
        int ch;
        while ((ch = getchar()) != '\n' && ch != EOF) ;   /* discard the rest */
        strcpy(buf, "?");                             /* force "invalid" */
    }
}

static int readInt(const char *prompt, int lo, int hi)
{
    char line[64], *end;
    long v;
    for (;;) {
        printf("%s", prompt);
        readLine(line, sizeof line);
        errno = 0;
        v = strtol(line, &end, 10);
        while (isspace((unsigned char) *end)) end++;
        if (end != line && *end == '\0' && errno == 0 && v >= lo && v <= hi)
            return (int) v;
        printf("  Invalid. Enter a whole number from %d to %d.\n", lo, hi);
    }
}

static double readNumber(const char *prompt, double lo, double hi, int loInclusive)
{
    char line[64], *end;
    double v;
    for (;;) {
        printf("%s", prompt);
        readLine(line, sizeof line);
        errno = 0;
        v = strtod(line, &end);
        while (isspace((unsigned char) *end)) end++;
        if (end != line && *end == '\0' && errno == 0 && isfinite(v)
            && (loInclusive ? v >= lo : v > lo) && v <= hi)
            return v;
        if (loInclusive) printf("  Invalid. Enter a number from %g to %g.\n", lo, hi);
        else             printf("  Invalid. Enter a number above %g, up to %g.\n", lo, hi);
    }
}

/* ---------- marks -> grade point (switch on 5-mark bands) ---------- */
static double marksToPoint(int marks, char *letter)
{
    const char *l;
    double gp;
    switch (marks / 5) {
        case 20: case 19: case 18: case 17: case 16: l = "A+"; gp = 4.00; break;  /* 80-100 */
        case 15:                                     l = "A";  gp = 3.75; break;  /* 75-79  */
        case 14:                                     l = "A-"; gp = 3.50; break;  /* 70-74  */
        case 13:                                     l = "B+"; gp = 3.25; break;  /* 65-69  */
        case 12:                                     l = "B";  gp = 3.00; break;  /* 60-64  */
        case 11:                                     l = "B-"; gp = 2.75; break;  /* 55-59  */
        case 10:                                     l = "C+"; gp = 2.50; break;  /* 50-54  */
        case 9:                                      l = "C";  gp = 2.25; break;  /* 45-49  */
        case 8:                                      l = "D";  gp = 2.00; break;  /* 40-44  */
        default:                                     l = "F";  gp = 0.00;         /* below 40 */
    }
    strcpy(letter, l);
    return gp;
}

/* ---------- letter -> grade point (nested switch); returns 1 if valid ---------- */
static int letterToPoint(const char *g, double *gp, char *letter)
{
    char c = (char) toupper((unsigned char) g[0]);
    char s = (g[0] != '\0') ? g[1] : '\0';
    if (g[0] == '\0' || (s != '\0' && g[2] != '\0')) return 0;   /* empty or too long */
    switch (c) {
        case 'A':
            switch (s) {
                case '+':  *gp = 4.00; break;
                case '\0': *gp = 3.75; break;
                case '-':  *gp = 3.50; break;
                default:   return 0;
            }
            break;
        case 'B':
            switch (s) {
                case '+':  *gp = 3.25; break;
                case '\0': *gp = 3.00; break;
                case '-':  *gp = 2.75; break;
                default:   return 0;
            }
            break;
        case 'C':
            switch (s) {
                case '+':  *gp = 2.50; break;
                case '\0': *gp = 2.25; break;
                default:   return 0;            /* no C- in this scale */
            }
            break;
        case 'D':
            if (s != '\0') return 0;
            *gp = 2.00;
            break;
        case 'F':
            if (s != '\0') return 0;
            *gp = 0.00;
            break;
        default:
            return 0;
    }
    letter[0] = c; letter[1] = s; letter[2] = '\0';
    return 1;
}

static void readGrade(const char *prompt, double *gp, char *letter)
{
    char line[64];
    for (;;) {
        printf("%s", prompt);
        readLine(line, sizeof line);
        char *g = line;
        while (isspace((unsigned char) *g)) g++;                       /* trim left  */
        size_t len = strlen(g);
        while (len > 0 && isspace((unsigned char) g[len - 1])) g[--len] = '\0';   /* trim right */
        if (letterToPoint(g, gp, letter)) return;
        printf("  Invalid. Use A+, A, A-, B+, B, B-, C+, C, D or F.\n");
    }
}

/* ---------- remark from CGPA (switch on 0.25-wide bands) ---------- */

        case 13:          return "Very good";       /* 3.25 - 3.49 */
        case 12:          return "Good";            /* 3.00 - 3.24 */
        case 11: case 10: return "Satisfactory";    /* 2.50 - 2.99 */
        case 9:  case 8:  return "Pass";            /* 2.00 - 2.49 */
        default:          return "Below pass level";
    }
}

    n    = readInt("Number of courses this semester (1-12): ", 1, MAX_COURSES);

    prevCredits = readNumber("Credits completed before this semester (0 if none): ", 0, 500, 1);
    if (prevCredits > 0)
        prevCgpa = readNumber("CGPA before this semester (0-4): ", 0, 4, 1);

    for (int i = 0; i < n; i++) {
        snprintf(p, sizeof p, "Course %d credit (above 0, up to 6): ", i + 1);
        credit[i] = readNumber(p, 0, MAX_CREDIT, 0);        /* 0 is not allowed */

        switch (mode) {
            case 1:
                snprintf(p, sizeof p, "Course %d marks (0-100): ", i + 1);
                gp[i] = marksToPoint((int) (readNumber(p, 0, 100, 1) + 0.5), letter[i]);
                break;
            case 2:
                snprintf(p, sizeof p, "Course %d grade: ", i + 1);
                readGrade(p, &gp[i], letter[i]);
                break;
            default:                                        /* cannot happen after readInt */
                printf("Internal error.\n");
                return 1;
        }
        semPoints  += gp[i] * credit[i];
        semCredits += credit[i];
        if (letter[i][0] == 'F') fails++;
    }

    if (semCredits <= 0) {                                  /* defensive check */
        printf("No valid credits, cannot calculate.\n");
        return 1;
    }

    printf("\n%-8s%-8s%-8s%-8s%s\n", "Course", "Credit", "Grade", "GP", "Points");
    for (int i = 0; i < n; i++)
        printf("%-8d%-8.2f%-8s%-8.2f%.2f\n", i + 1, credit[i], letter[i], gp[i], gp[i] * credit[i]);

    double gpa  = semPoints / semCredits;
    double cgpa = (prevCgpa * prevCredits + semPoints) / (prevCredits + semCredits);

    printf("\nSemester credits : %.2f\n", semCredits);
    printf("Semester GPA     : %.2f\n", gpa);
    if (prevCredits > 0)
        printf("Total credits    : %.2f\n", prevCredits + semCredits);
    printf("CGPA             : %.2f (%s)\n", cgpa, remark(cgpa));
    if (fails > 0)
        printf("Warning: %d course(s) with grade F count as 0.00 points. Retake them to improve.\n", fails);
    return 0;
}

Where the switch is used: marksToPoint (marks / 5 bands), letterToPoint (nested switch on letter and sign), remark (CGPA bands) and the input mode in main. Compile with gcc cgpa.c -o cgpa -lm.

10. Conditional operator #

The conditional (ternary) operator ?: is the only C operator with three operands. It is a compact form of if-else that produces a value.

result = (condition) ? value_if_true : value_if_false;

The condition is evaluated first. If it is non-zero, only the middle expression is evaluated; otherwise only the last one.

Examples

int max  = (a > b) ? a : b;                         // larger of two
int abs  = (n < 0) ? -n : n;                        // absolute value
printf("%s\n", (n % 2 == 0) ? "Even" : "Odd");      // directly inside printf
char *r = (marks >= 40) ? "Pass" : "Fail";

Nested (chained) use

// largest of three
int big = (a > b) ? ((a > c) ? a : c) : ((b > c) ? b : c);

// grade chain: reads like an else-if ladder
char *g = (marks >= 80) ? "A+" :
          (marks >= 70) ? "A"  :
          (marks >= 60) ? "B"  : "F";

// leap year
printf("%s", ((y%4==0 && y%100!=0) || y%400==0) ? "Leap" : "Not leap");

Associativity is right to left, so c1 ? x : c2 ? y : z means c1 ? x : (c2 ? y : z).

Equivalent if-else

if (a > b) max = a;        // same as:  max = (a > b) ? a : b;
else         max = b;

ATM menu with switch inside a loop

#include <stdio.h>

int main()
{
    int choice;
    double balance = 1000, amount;
    do {
        scanf("%d", &choice);
        switch (choice) {
            case 1:
                scanf("%lf", &amount);
                balance += amount;
                printf("Deposited %.2f\n", amount);
                break;
            case 2:
                scanf("%lf", &amount);
                if (amount <= balance) {
                    balance -= amount;
                    printf("Withdrawn %.2f\n", amount);
                } else {
                    printf("Insufficient balance\n");
                }
                break;
            case 3:
                printf("Balance = %.2f\n", balance);
                break;
            case 4:
                printf("Thank you\n");
                break;
            default:
                printf("Invalid choice\n");
        }
    } while (choice != 4);
    return 0;
}
